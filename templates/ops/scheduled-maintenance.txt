- The API returns an error on every request.

closes.

What keeps working

- Your data stays where it is. Nothing is deleted or changed.
- Work you saved before [MAINTENANCE_START] is there when the
window closes.
- The status page stays up for the whole window.

edit that is still going when the window opens will fail part way
through.

the window and let it retry afterwards, rather than treating the
failure as final.
